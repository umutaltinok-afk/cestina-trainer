# Čeština 1–6

Single-file drill trainer for *Česky krok za krokem 1*, Lekce 1–6: 353 items across six item types, English explanations, Czech forms with exact diacritics, spaced repetition in the browser.

**Install on iPhone:** open the site in Safari → Share → *Add to Home Screen*. It runs full-screen and offline after the first visit. Progress stays on the device; use *Progress → Export* to move it.

Built from `cestina-1-6.html` with `_tools/trainer/build_site.py` in the authoring project; this repository holds only the deployable site.
